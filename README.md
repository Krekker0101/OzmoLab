# «Озмо Лаб» (Ozmo Lab) 🧪⚡

Платформа интерактивных виртуальных лабораторий (электротехника, физика, биология) с интеллектуальным ИИ-наставником для школьников Таджикистана.
Поддерживает два языка интерфейса и наставника: **таджикский (`tg`)** и **русский (`ru`)**.

---

## 1. Структура проекта (Monorepo)

Архитектура проекта организована по принципу модульного монорепозитория с чётким разделением ответственности:

## 2. Быстрый запуск

### Предварительные требования
- Node.js $\ge 20$
- npm $\ge 10$

### Команды

```bash
# 1. Запуск в режиме разработки (Full-Stack dev сервер на порту 3000)
npm run dev

# 2. Запуск модульных тестов (Vitest)
npm test

# 3. Запуск 15 оценочных сценариев для ИИ-наставника (Eval Suite)
npm run eval

# 4. Проверка типов TypeScript (strict: true)
npm run lint

# 4. Продакшен сборка
npm run build

# 5. Запуск продакшен сервера
npm start
```

При запуске `npm run dev` приложение открывается по адресу [http://localhost:3000](http://localhost:3000).

## 3. Модульная система лабораторий: как добавить новую лабораторию

Каждая лаборатория оформляется как изолированный плагин, реализующий контракт `LabModule` из `/shared/types.ts`:

```typescript
export interface LabModule {
  id: string;                                   // Уникальный ID ('chemistry-titration', 'optics-wave')
  titleKey: string;                             // Ключ названия в i18n
  descriptionKey: string;                       // Ключ описания в i18n
  discipline: 'physics' | 'circuits' | 'optics' | 'biology';
  components: ComponentDefinition[];            // Доступные элементы с терминалами и параметрами
  simulate: (state: LabState) => SimulationResult; // Детерминированный расчёт физики
  describeState: (state: LabState) => AISummarySnapshot; // Проекция состояния для ИИ-наставника
  lessons: Lesson[];                            // Практикум и обучающие шаги с автовалидацией
  defaultState?: Partial<LabState>;             // Начальное состояние стола
}
```

### Пошаговое руководство добавления нового плагина (например, «Термодинамика»):

1. **Создайте директорию плагина**:
   Создайте папку `/web/src/labs/thermodynamics/index.ts`.

2. **Опишите логику лаборатории**:
   ```typescript
   import { LabModule, LabState, SimulationResult, AISummarySnapshot } from '../../../../shared/types.ts';

   export const ThermodynamicsModule: LabModule = {
     id: 'thermodynamics-calorimeter',
     titleKey: 'labs.thermo.title',
     descriptionKey: 'labs.thermo.desc',
     discipline: 'physics',
     components: [
       // Определение калориметра, термометра, нагревателя
     ],
     simulate: (state: LabState): SimulationResult => {
       // Расчёт теплового баланса Q = c * m * ΔT
       return {
         isClosedCircuit: true,
         hasShortCircuit: false,
         totalCurrent: 0,
         totalEquivalentResistance: 0,
         componentStates: {},
         warnings: [],
       };
     },
     describeState: (state: LabState): AISummarySnapshot => {
       // Формирование компактного объекта для передачи ИИ-наставнику
       return {
         labId: 'thermodynamics-calorimeter',
         summaryText: 'Калориметр с водой при температуре 22°C',
         isCircuitComplete: true,
         hasHazard: false,
         activeComponentsCount: state.components.length,
         components: [],
         connectionsCount: 0,
       };
     },
     lessons: [
       // Шаги лабораторной работы по удельной теплоёмкости
     ],
   };
   ```

3. **Зарегистрируйте модуль в реестре (`/web/src/labs/init.ts`)**:
   ```typescript
   import { LabRegistry } from './registry.ts';
   import { ThermodynamicsModule } from './thermodynamics/index.ts';

   export function initializeLabModules(): void {
     // ...
     LabRegistry.register(ThermodynamicsModule);
   }
   ```

4. **Добавьте языковые ключи в `/shared/i18n.ts`** для таджикского и русского языков.
   **Ядро платформы, монтажный стол и коммуникация с ИИ автоматически подхватят новую лабораторию без изменений в коде ядра!**

## 4. Двуязычная система и верификация глоссария учителями

Все строки интерфейса строго локализованы через функцию `t(key, lang, params)` из `/shared/i18n.ts`.

В файле `/shared/glossary.json` зафиксирован терминологический глоссарий для школ Таджикистана.
Все первоначальные переводы на таджикский язык имеют статус:
```json
"verified": false
```
В интерфейсе платформы (кнопка «Луғати истилоҳот / Словарь терминов» в шапке) термины с `verified: false` отмечены жёлтым индикатором «Тасдиқ нашудааст / Не верифицировано». Это даёт учителям физики возможность просмотреть термины, сверить их со школьными стандартами Таджикистана и подтвердить корректность.

## 5. Переменные окружения (Environment Variables)

Все конфиденциальные переменные хранятся исключительно на сервере и никогда не попадают в клиентскую сборку Vite (`dist/`):

| Переменная | Описание | Обязательность | Значение по умолчанию |
|---|---|---|---|
| `BASETEN_API_KEY` | API-ключ Baseten для модели Meta Muse Spark Open (мультимодальное зрение схем + ИИ-тьютор) | Опционально (при отсутствии работает детерминированный офлайн-солвер и локальный тьютор) | `""` |
| `BASETEN_MODEL_ID` | Идентификатор модели на платформе Baseten | Опционально | `meta-models/muse-spark-open-1026` |
| `BASETEN_API_URL` | URL эндпоинта Baseten API | Опционально | `https://inference.baseten.co/v1` |
| `EVAL_FAST` | Флаг быстрого выполнения оценочных тестов | Опционально | `false` |
| `APP_URL` | Публичный адрес развернутого инстанса приложения | Опционально | `http://localhost:3000` |
| `PORT` | Порт Express-сервера | Опционально | `3000` |

## 6. Бесплатный деплой (Free Deployment)

Для стабильного размещения full-stack приложения (Node.js/Express + статика Vite) без риска утечки API-ключей в браузер настроен деплой через **Render.com Free Web Service** (или Fly.io / Railway):

1. **Характеристики бесплатного тарифа Render Free Tier**:
   - 512 MB RAM, 0.1 vCPU (достаточно для легковесного Express и MNA-солвера).
   - Поддержка автоматического HTTPS-сертификата (Let's Encrypt).
   - Поддержка секретов через Environment Variables в панели Render.
   - Спящий режим (spin-down) после 15 минут неактивности; запуск при первом запросе за ~30–50 секунд.
2. **Файл конфигурации `render.yaml`**:
   - В корне репозитория подготовлен `render.yaml` со спецификацией сервиса:
     - Health check path: `/health`
     - Build command: `npm install && npm run build`
     - Start command: `npm start`
     - `sync: false` для `BASETEN_API_KEY` (секрет вводится пользователем в UI панели).
3. **Единственный шаг со стороны пользователя**:
   - Зайти на [render.com](https://render.com), нажать **New +** -> **Blueprint**, подключить свой репозиторий GitHub и ввести значение `BASETEN_API_KEY` в поле переменных окружения. Всё остальное поднимется автоматически.
4. **Бесплатный подогрев сервера (Zero-Cost Keep-Warm)**:
   - В репозитории добавлен GitHub Actions workflow `.github/workflows/keep-warm.yml`.
   - По расписанию каждые 14 минут (`cron: '*/14 * * * *'`) он отправляет лёгкий HTTP GET запрос на эндпоинт `/health`, предотвращая засыпание бесплатного инстанса Render без каких-либо платных подписок.
   - Альтернативно можно настроить бесплатный мониторинг на [cron-job.org](https://cron-job.org) или [uptimerobot.com](https://uptimerobot.com) с интервалом 5–10 минут.
5. **Безопасность ключей**:
   - Ключ `BASETEN_API_KEY` считывается только на бэкенде.
   - Клиентский бандл `dist/` компилируется без передачи ключей (проверено строгим аудитом содержимого файлов на фактическое значение ключа: 0 совпадений).

## 7. Надёжность и защита от сбоев (Reliability & Rate Limiting)

1. **Легковесный эндпоинт проверки здоровья `/health`**:
   - Возвращает `{ status: 'ok', uptime: <seconds>, timestamp: <iso>, service: 'ozmo-lab' }` с кодом HTTP 200 без прохождения через тяжёлые middleware или парсеры.
2. **Глобальный таймаут запросов**:
   - Все сетевые вызовы к Vision API и LLM защищены таймаутом `AbortSignal.timeout(20000)` (20 секунд).
3. **Двухуровневый Rate Limiter и Token Cap**:
   - **Уровень 1 (Per-IP / сессия)**:
     - До 30 запросов в минуту с одного IP-адреса.
     - До 40 000 токенов в час на IP-адрес.
     - Дружелюбное локализованное сообщение на таджикском, русском и английском языках с заголовком `Retry-After`.
   - **Уровень 2 (Глобальный защитный лимит сервера)**:
     - До 100 запросов в минуту суммарно от всех пользователей.
     - До 120 000 токенов в час суммарно для предотвращения исчерпания баланса API.
     - Дружелюбное сообщение о временной загруженности сервера.
4. **Отказоустойчивость при нечитаемых фото или отсутствии интернета**:
   - Если загружено нечитаемое фото, конспект или посторонний предмет, модель возвращает структурированный ответ с кодом `not_readable` и понятными рекомендациями (улучшить освещение, повернуть лист). Экран ошибки пустой никогда не отображается.
   - При недоступности Baseten API или отсутствии ключа система автоматически активирует детерминированный симулятор и офлайн-правила тьютора.

## 8. Измеренные результаты и честные ограничения (Known Limitations)

1. **Что работает гарантированно (протестировано 146 тестами Vitest)**:
   - Полный сквозной флагманский сценарий: выбор/загрузка схемы -> верификация нетлиста -> детерминированный MNA-расчёт токов/узлов/сопротивления -> генерация объяснения учителя физики на таджикском (`tg`) и русском (`ru`) языках.
   - Автоматическая трансляция синтезированных и распознанных схем на интерактивный монтажный стол с каноническими терминалами (`pos`/`neg`, `term_a`/`term_b`).
   - Экспорт телеметрии датчиков в CSV в журнале наблюдений.
   - Двуязычный физический глоссарий для школ Таджикистана с пометками учительской валидации.
2. **Ограничения физического движка**:
   - Движок MNA (Modified Nodal Analysis) рассчитывает цепи **постоянного тока (DC)**. Переменный ток (AC), реактивные сопротивления катушек индуктивности и конденсаторов во временной области в текущей версии v1 не моделируются.
3. **Что пока не доработано (What is NOT finished)**:
   - **3D-монтаж проводов**: 3D-сцена Three.js корректно отображает компоненты и состояние (свечение лампы, вращение ротора), но интерактивная протяжка проводов мышью выполняется на 2D SVG-столе; в 3D протяжка проводов курсором находится в экспериментальном статусе.
   - **Лаборатории оптики и биологии**: реализованы как подключаемые прототипы модулей с уроками и каталогом элементов, но не имеют столь глубокого математического солвера, как цепи DC.
   - **Камера в iOS Safari в iFrame**: прямое чтение с видеопотока веб-камеры внутри некоторых iFrame-контейнеров может блокироваться политиками Permissions-Policy; в этом случае используется гарантированная загрузка фото через `<input type="file">`.
